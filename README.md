# Aviation Data Analysis – Global Flight Delay & Airport Operations

This project analyzes global flight operations data to understand **flight delays, airline performance, and airport efficiency** using **SQL, Python, and Power BI**.

## Project Overview

Air travel generates massive operational data. This project explores flight data to identify **delay patterns, airline performance, and frequently used routes**.

The goal is to extract actionable insights that can help improve **operational efficiency and passenger experience** in aviation.

* Total flights by airline
* Average arrival delays by airline
* Airports with highest departure delays
* Most frequent flight routes
* Route-level delay analysis
* Cancelled flights by airline

## How to Run the Project

1. Download or clone the repository
2. Open `flights.ipynb` using **Jupyter Notebook** or **VS Code**
3. Run the SQL queries in `flight_analysis.sql`
4. Explore the **Power BI dashboard** using the provided download link
